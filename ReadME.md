Project Description
Choose Your Path is a PHP-based RPG game with a branching story. Players make choices that affect the story and determine which ending they receive.

The game follows a protagonist who encounters an injured woman and gets pulled into the world of magical heroes. Players can choose how the story progresses and discover different endings.
Features
- User registration and login
- User logout
- Branching story with player choices
- Three possible endings
- Ending map to track discovered endings
- PHP sessions to manage user information and game progress
Files
- index.php – Main menu
- register.php – User registration
- login.php – User login
- logout.php – User logout
- game.php – Main game and story choices
- endingmap.php – Displays discovered endings
- style.css – Page styling
- data/users.txt – Stores user account information
How to Play
1. Open the main page.
2. Register a new account or log in.
3. Start the game.
4. Read the story and select your choices.
5. Discover the different endings.
6. Visit the ending map to see which endings you have found.
